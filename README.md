## よくある質問 (FAQ)

**Q1: 既存のBitwig Studioの設定やプロジェクトに影響はありますか？**
A: いいえ、このツールは既存の環境にプラグインとプリセットを追加するのみです。設定ファイルを上書きしたり、プロジェクトファイルを変更したりすることはありません。安全にアンインストールすることも可能です。

**Q2: Bitwig Studioのどのバージョンに対応していますか？**
A: 2026年リリースのBitwig Studio（バージョン5.x以降）に完全対応しています。それ以前のバージョンとの互換性は保証されません。最新版への更新を推奨します。

**Q3: インストール後にプラグインがBitwig Studioに表示されない場合はどうすればいいですか？**
A: まずBitwig Studioを再起動してください。それでも解決しない場合は、Bitwig Studioの「設定」→「プラグイン」で、プラグイン検索パスが正しく設定されているか確認し、「再スキャン」を実行してください。

**Q4: このツールを使用するのにBitwig Studioのライセンスキーは必要ですか？**
A: はい、Bitwig Studio自体は正規のライセンスキーで起動する必要があります。本ツールは、その正規環境を拡張および強化するための追加パッケージです。
